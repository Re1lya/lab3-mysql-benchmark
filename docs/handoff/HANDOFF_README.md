# 实验三材料目录

| 内容 | 位置 |
| --- | --- |
| 精简实验报告（Word、PDF） | `实验报告/` |
| 按指导书步骤重新部署、测试 | `操作手册/`，命令可从 `详细操作步骤.md` 复制 |

| 报告“扩展测试”的原始数据 | `原始数据/02_参考样例负载测试/`：读取1000–1200线程、2循环；写入1000–1300线程、1循环；两实现各3轮，共54组 |
| 每组参数、轮次、文件位置 | `原始数据/测试组索引.csv` |

| 各组JMeter可视化报告 | `JMeter可视化报告/测试类别/中文组名/index.html` |

| 编译、部署和采集记录 | `过程记录/` |
| 程序、JMX、部署和监控配置 | `实验程序/` |

原始数据按“测试类别 → JPA或MyBatis读写测试 → 参数与轮次”分组。例如：`JPA读取_1000线程_10秒升压_1次循环_第1轮.jtl`。同组保存测试参数、日志，以及活跃线程、CPU、内存三项监控原始数据。

共90组、111600条请求，保留全部重复轮次，包括性能未达标的轮次。第一类完成指导书要求的读写性能对比设计，第二类参考报告样例的负载设置。

文件整理只改名称，不改原始数据。`完整性校验/文件名对照表.csv` 记录原路径；执行 `python 完整性校验/校验文件.py` 可核对全包。JMeter网页内部文件及程序文件保留原名，保证能正常打开和运行。

程序仓库：https://github.com/Re1lya/lab3-mysql-benchmark
