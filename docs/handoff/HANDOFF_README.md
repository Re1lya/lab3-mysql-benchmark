# 实验三验收材料

| 文件或目录 | 对应实验内容与用途 |
| --- | --- |
| 实验报告/ | 实验设计、结果和图表，含Word与PDF |
| 操作手册/ | 按指导书部署、运行测试；最后一节说明验收展示顺序和指标含义 |
| 原始数据/01_JPA读取/ | JPA读取性能测试，样例5个线程档位，共5份JTL |
| 原始数据/02_JPA写入/ | JPA写入性能测试，样例4个线程档位，共4份JTL |
| 原始数据/03_MyBatis读取/ | MyBatis读取测试，用于读写及框架对比，共5份JTL |
| 原始数据/04_MyBatis写入/ | MyBatis写入测试，用于读写及框架对比，共4份JTL |
| 原始数据/05_Prometheus监控/ | 指导书要求的活跃线程、CPU、内存监控；每组一个JSON，含三项查询结果及测试参数 |
| 原始数据/测试组索引.csv | 每组参数、请求数及JTL、监控、网页报告的位置 |
| 数据统计/测试结果汇总.csv | 上述18组的响应时间、P95、40ms内成功比例等统计 |
| JMeter测试报告.zip | 18组JMeter网页报告，整体解压后打开对应组index.html |
| 过程截图/ | 环境配置、18组测试概览；原生图表/为各组JMeter结果概览、响应时间趋势和百分位；运行监控/为Prometheus活跃线程、CPU及内存页面 |
| 实验程序.zip | 应用源码、JMX、部署及监控配置 |

读取：1000/1050/1100/1150/1200线程、10秒升压、2循环；写入：1000/1100/1200/1300线程、10秒升压、1循环。JPA与MyBatis各执行一套。

本次提交统一使用原采集第一轮，共18组31200次请求，JTL内容未改。文件名直接标明实现、读写、参数和轮次。验收可按“报告结果→统计CSV→对应JTL及JMeter报告→监控记录”查看。

报告按样例逐档展示MyBatis的JMeter图表，JPA结果及两种实现的比较见表格。原生图表和运行监控截图于2026年10月21日从原JMeter报告及Prometheus历史页面补截，均对应10月18日的原测试数据。

程序仓库：https://github.com/Re1lya/lab3-mysql-benchmark
