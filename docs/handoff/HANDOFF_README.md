# 实验三材料目录

本包包含10页实验报告、操作手册、程序及报告对应的全部原始数据。

| 要查看的内容 | 位置 |
| --- | --- |
| 实验报告 Word和PDF | `实验报告/` |
| 按实验三指导书编排的操作手册 | `操作手册/实验三_组员操作手册.pdf`；可复制命令见同目录 `详细操作步骤.md` |
| JPA与MyBatis基本读写测试 | `原始数据/基本测试/`：100、400、1000线程，10秒升压，1循环，各3轮，共36组 |
| JPA与MyBatis扩展读取测试 | `原始数据/扩展测试/` 中名称含 `ReadProduct` 的组：1000–1200线程，2循环，共30组 |
| JPA与MyBatis扩展写入测试 | `原始数据/扩展测试/` 中名称含 `WriteProduct` 的组：1000–1300线程，1循环，共24组 |
| 全部测试组参数及文件位置 | `原始数据/测试组索引.csv` |
| 功能测试结果 | `过程记录/基本测试/logs/` 下的 `test-jpa.log`、`test-mybatis.log`、`tests-final.json` |
| 汇总数据与报告图表 | `统计与图表/基本测试/`、`统计与图表/扩展测试/` |
| 各组JMeter报告 | `JMeter可视化报告/基本测试或扩展测试/组名/index.html` |
| 实验过程截图和操作日志 | `过程截图/`、`过程记录/`，均按基本测试和扩展测试分开 |
| 程序、JMX、部署和监控配置 | `实验程序/` |

每个性能测试组中：`samples.jtl` 是原始请求数据，`metadata.json` 记录参数与数据库变化，`prometheus-*.json` 是原始监控时序，其余为日志和起止时间。组名中的 `jpa/mybatis` 表示实现，`ReadProduct/WriteProduct` 表示读写，`r1/r2/r3` 表示轮次，`t` 表示线程数，扩展组的 `l` 表示循环数。

例如，基本测试 `jpa-r1-ReadProduct-t1000/samples.jtl` 是JPA读取、1000线程、第1轮的原始数据。报告使用的两批数据共90组、111600条请求，所有轮次均保留；原始数据附SHA-256清单。解压后可运行 `python 完整性校验/verify.py` 校验全包。

程序仓库：https://github.com/Re1lya/lab3-mysql-benchmark
